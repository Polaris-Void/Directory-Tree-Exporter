# تحلیل‌گر ساختار درختی و متادیتای فایل‌ها (Directory Tree & File Metadata Auditor)

یک ابزار دقیق، سریع و خودکار تحت سیستم‌عامل ویندوز (ترکیب Batch Script و PowerShell) جهت اسکن کامل دایرکتوری‌ها، ترسیم نمودار درختی پوشه‌ها و استخراج متادیتای دقیق فایل‌ها در قالب یک گزارش متنی تمیز و ساختاریافته با انکودینگ UTF-8.

---

## ✨ قابلیت‌ها و ویژگی‌ها

* **🌳 ترسیم نمودار درختی ساختار پوشه‌ها:** نمایش سلسله‌مراتبی و بازگشتی (Recursive) فایل‌ها و پوشه‌ها با استفاده از نمادهای گرافیکی خط فرمان (`├──`, `└──`, `│`).
* **📊 استخراج متادیتای کامل:** محاسبه و نمایش حجم فایل‌ها به شکل خوانا (بایت، کیلوبایت، مگابایت، گیگابایت) به همراه تاریخ و ساعت دقیق ساخت (Creation) و آخرین تغییرات (Last Modified).
* **📐 تنظیم داینامیک فاصله‌گذاری ستون‌ها:** محاسبه خودکار طولانی‌ترین نام فایل یا مسیر، جهت جلوگیری از به‌هم‌ریختگی ستون‌ها و حفظ ساختار یکپارچه جدول گزارش.
* **📈 گزارش آماری جامع:** شمارش دقیق تعداد کل پوشه‌ها، فایل‌های پردازش‌شده، مجموع حجم داده‌ها (به فرمت خوانا و تعداد دقیق بایت‌ها) و زمان‌سنجی سرعت اجرا به ثانیه.
* **🌍 پشتیبانی کامل از UTF-8:** استفاده از کدگذاری UTF-8 (همراه با BOM) برای جلوگیری از خراب شدن متون و نام فایل‌های فارسی، کاراکترهای خاص و علائم شاخه‌ای.
* **🛡️ عدم تداخل با فایل گزارش:** نادیده گرفتن خودکار فایل خروجی (`File List Log.txt`) در طول اسکن برای ثبت نشدن اطلاعات اضافه در گزارش.
* **⚡ ۱۰۰٪ بومی و سبک:** بدون نیاز به نصب پایتون، نودجی‌اس یا ابزارهای جانبی (کاملاً متکی بر محیط پیش‌فرض ویندوز).
